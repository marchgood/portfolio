PROJECT 01

Aplikasi Kredit Perabot.

Aplikasi desktop sederhana yang dibuat untuk membantu proses transaksi kredit perabot rumah. Project ini menggunakan C# dan dikembangkan melalui Visual Studio.

Tentang Project

Aplikasi ini merupakan project pembelajaran pemrograman desktop. Di dalamnya terdapat proses input data, pilihan produk, perhitungan transaksi, dan tampilan antarmuka aplikasi.

Technologies

C# Visual Studio Windows Forms Programming
