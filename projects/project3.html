PROJECT 03

Arduino Smart E-Toll.

Prototype sistem gerbang tol otomatis berbasis Arduino yang dirancang untuk mendeteksi kendaraan dan membantu proses simulasi pembayaran menggunakan sistem elektronik.

Tentang Project

Project ini dibuat sebagai latihan Internet of Things dan pemrograman mikrokontroler. Arduino digunakan sebagai pusat pengendali sistem dengan sensor untuk mendeteksi kendaraan yang berada di sekitar gerbang.

Fitur

  • Deteksi kendaraan menggunakan sensor
  • Sistem gerbang otomatis
  • Indikator suara menggunakan buzzer
  • Pemrosesan data melalui Arduino
  • Simulasi sistem E-Toll

Technologies

Arduino Uno Arduino IDE Ultrasonic Sensor Buzzer C++ IoT
